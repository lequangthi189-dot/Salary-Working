One-line: status chips — Planned, Overdue, ✓ Received, machine-read.

```jsx
<Badge kind="planned">Planned</Badge>
<Badge kind="overdue">Overdue — not checked in</Badge>
<Badge kind="received">✓ Received</Badge>
<Badge kind="ocr">read from image</Badge>
```

`ocr` is a dashed outline on purpose: a number the machine read must never look like a number the person entered.
