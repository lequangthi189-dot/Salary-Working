Logo

One mark: Bảng kẹp, the clipboard ledger you supplied (uploads/sw-29-bangkep-icon.svg). Kept as drawn — only the reconcile stroke gained round caps, and a lockup plus a light-ground variant were built around it. No alternative directions are proposed.

A hairline clipboard frame holds a solid header row, three tick boxes and three half-opacity data rows — the exact anatomy of the app's shift list. One maroon check crosses the last rows: the reconcile stroke, drawn by the worker, not by the system.

Construction is additive and orthogonal — every element sits on a 4px sub-grid of the 256 box, corner radii are 2/5/7/12, and the structure holds one stroke weight throughout: 9. The check is heavier at 16 and is the only diagonal in the mark, so it carries the emphasis without a gradient or a glow.

Idea
A record you keep and sign off yourself.
Colour
Ink navy structure, 55% opacity data rows, ledger maroon accent — deliberately not SaaS blue.
On dark
Use a-bangkep-icon-light.svg. The base file draws with currentColor, so inside HTML you can also just set color on an inlined copy.
Sizes
Holds at 16px because the frame survives when the rows blur. Below 16px, drop the data rows and keep frame + check.
Clear space
Half the clip width on every side; never place the mark on a photo or a gradient.
Don't
Recolour the check to the accent blue, rotate the mark, add a container tile behind it, or set the wordmark in anything but the OS UI stack.
